# UI17 installation

[Download CatAI-17.apk](CatAI-17.apk) — AI planner, live plan cards, local task search and Bluetooth remote.

[Download CatBT-17.apk](CatBT-17.apk) — Bluetooth remote and the same local search/library, with no Internet/camera/microphone capability.

Install one variant at a time; both use `com.blackcat.remote` and the original signer.
Version code 21 can update the previous candidate. The app uses your on-phone API key
for AI; no cloud test key is included. Search needs no key or model download.

APK source: `9c1738a32721fcc9970a2795b6c81bb72bb5e297`. Exact tested APK bytes were copied without rebuilding to rename them.
