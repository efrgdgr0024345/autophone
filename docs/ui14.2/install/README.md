# Install UI14.2

Download [CatAI-14.2.apk](CatAI-14.2.apk) directly and open it on the phone.
This is an Android APK, not a ZIP. Approve installation from the browser/file app
if Android asks. The original signing certificate and package identity are retained;
a normal update install preserves app data. No uninstall should be necessary for
the same-signer upgrade. Install one flavor at a time.

CatAI includes planning, foreground Auto, image feedback, OpenAI speech and the
offline command library. Add or retain your own API key in Settings. The cloud test
key is never included in the app. CatBT is the offline keyboard/mouse/library alternative.

Version code 18, `14.2-live-api-validation`. See [SHA256SUMS.txt](SHA256SUMS.txt),
[SOURCE.txt](SOURCE.txt), signing reports and the [verification report](../README.md).
The app remains a physical-test candidate; previous releases are unchanged.
