# Install UI15

Download [CatAI-15.apk](CatAI-15.apk) directly and open it on the phone.
This is an APK, not a ZIP. If Android asks, allow installation from the browser
or file app. The original app identity and signer are retained for an ordinary
update install; no uninstall should be necessary. Install one variant at a time.

CatAI retains AI planning, Auto, voice, image feedback and the expanded offline
Kali/Linux library. CatBT is the offline keyboard/mouse/library alternative.
Catalogue browsing needs no API key. This update adds no permissions or tool
installations; inventoried programs belong to the Linux computer, not the phone.

Version code 19, `15.0-offline-kali-learning`. See [SOURCE.txt](SOURCE.txt),
[SHA256SUMS.txt](SHA256SUMS.txt), signing reports and the
[verification report](../VERIFICATION.json). Both files are testing candidates;
physical phone/computer acceptance remains required.
