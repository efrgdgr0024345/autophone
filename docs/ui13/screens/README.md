# UI13 rendered phone screens

These 36 PNGs are actual app-window PixelCopy captures from the exact published APK. Auto Play and Voice remain pinned above scrolling content. Vision/planner/HID replies are synthetic fixtures; Camera2 JPEG capture is real on the disposable emulator. No paid API request or physical HID send is used.

The core 16 checks passed in the full run; that run later exceeded the software emulator deadline during Auto. The four Auto cases passed in a focused rerun with a longer test-only timeout. Both original logs are included here. The app APK was unchanged between these runs.
