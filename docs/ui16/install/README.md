# Install UI16

Download [CatAI-16.apk](CatAI-16.apk) and open it on the phone. This is a direct
Android installer file. Allow installation from the browser/file app if Android
asks. Original package identity and signer are retained for a normal update;
no uninstall should be necessary. Install one flavor at a time.

CatAI includes full offline Kali workflows, the keyboard/mouse remote and the
existing AI/Auto/voice/photo features. CatBT is the offline remote/library alternative.
The expanded directory, guides and task builder need no API key. Remote AI requests
still use your own key in Settings. No cloud key is included in either APK.

Open **Kali Linux → All Kali command workflows** for the 3,055 command entries.
The Kali tool directory covers all 820 groups. Package-only collections have
version/status/file guides. Commands have documented discovery steps, literal
argument editing and exact review; whole guides can be added to an AI plan locally.
Ordinary TYPE ONLY still requires a fresh approval and manual Enter. Auto retains
its separate command subset; not every imported guide or prepared task is eligible.

Version code 20, `16.0-full-kali-workflows`. See [SOURCE.txt](SOURCE.txt),
[SHA256SUMS.txt](SHA256SUMS.txt), signing reports and [verification](../VERIFICATION.json).
Tool programs must be available on the target Linux computer; this APK does not
install the 820 packages on Android. Actual phone/computer Bluetooth and tool
execution need physical acceptance. Earlier APKs remain unchanged.
