# Black Cat Remote

Public Android test app that makes a compatible Android phone act as a Bluetooth HID keyboard and mouse.

## Current controls
- Choose an already-paired Bluetooth computer
- Connect / Disconnect
- Text box + **SEND TEXT**
- Large touchpad: drag to move the pointer
- Tap touchpad for left click
- Separate left/right click buttons

## Download
The latest APK is published automatically under **Releases → latest**.

## Security
This is an experimental HID controller. Test it first on a non-sensitive session. Bluetooth HID can inject keyboard and mouse input into the connected computer.

## Android requirements
Android 9 / API 28 or newer, with Bluetooth HID Device support exposed by the handset.
